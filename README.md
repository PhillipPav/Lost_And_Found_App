# Lost and Found App

An android studio mobile application that allows users to create adverts for lost and found items to connect them with their owners. Created by Phillip Pavlides for SIT305 at Deakin University

## Installation
*   Open Git Bash
*   Clone the repository: `git clone https://github.com/PhillipPav/Lost_And_Found_App`

## Usage
This Program allows users to create and manage a list of lost and found adverts  
*   Home page features as the main navigation and displays two buttons leading to the Create Advert and Show Advert pages.
*   The user can create new adverts of items that are either lost or found.
*   The Create New Advert page is where users must enter all the relevant data (*post type, title, category, phone number, description, date, and location*) and create an event with given data
*   The adverts also require an attached image that prompts the user to select an existing image from their device photo library.
*   The Show Adverts page lists all exisitng lost and found adverts, which the user can filter by category.
*   By clicking on an advert the user can view additional details, and remove the advert if the item has been returned to it's owner.
*   The app has data persistance and will retain the adverts list even after closing and reopening the app
